# 🏫 โครงงานเว็บข่าวสารโรงเรียน + ระบบแจ้งเตือน OneSignal (React)

ระบบเว็บข่าวสารโรงเรียนที่โฟกัสเฉพาะแกนหลักที่ใช้งานได้จริง:
**"ครูลงข่าว → เลือกระดับชั้น → กดส่ง → มือถือกลุ่มนั้นได้รับแจ้งเตือนทันที"**

---

## 🎯 ฟังก์ชันการทำงานหลัก (Core Features)

1. **ฝั่งนักเรียนและผู้ปกครอง (หน้าดูข่าว)**:
   - **ไม่ต้องสมัครสมาชิก / ไม่ต้อง Login**
   - มีปุ่มเลือกชั้นเรียน (ม.1, ม.2, ม.3, ม.4, ม.5, ม.6, ผู้ปกครอง)
   - กดปุ่ม **"ยืนยันรับแจ้งเตือนกลุ่มนี้"** เพื่อบันทึก OneSignal Data Tag (`level = m1`) ในคลิกเดียว

2. **ฝั่งคุณครู (แผงควบคุม Admin)**:
   - เข้าสู่ระบบด้วยรหัสผ่านสั้นๆ (รหัสเริ่มต้น: `1234`)
   - **เพิ่มข่าวใหม่ / แก้ไขข่าว / ลบข่าว**
   - เลือกระดับชั้นเป้าหมายที่ต้องการให้ข่าวไปปรากฏ
   - ช่องติ๊ก `[x] ส่งการแจ้งเตือน OneSignal ไปยังมือถือของระดับชั้นนี้ทันที`

3. **ระบบการแจ้งเตือน (OneSignal Web Push)**:
   - ส่งตรงถึงผู้ใช้ผ่าน OneSignal REST API โดยกรองตาม User Data Tag อัตโนมัติ

## 🚀 วิธีนำขึ้นโฮสติ้งฟรี (Free Hosting with HTTPS)

เบราว์เซอร์บนมือถือต้องการ **HTTPS** เพื่อเปิดใช้งาน Web Push Notification คุณสามารถนำโฟลเดอร์นี้ขึ้นโฮสติ้งฟรีได้ง่ายๆ ภายใน 2 นาที:

### วิธีที่ 1: อัปโหลดผ่าน Vercel (แนะนำที่สุด ⭐)
1. ไปที่ [vercel.com](https://vercel.com/) แล้วสมัครสมาชิกฟรีด้วย GitHub
2. ลากโฟลเดอร์โปรเจกต์นี้วางลงในหน้าเว็บ Vercel (หรือกด New Project จาก GitHub Repo)
3. กด **Deploy** จะได้ลิงก์เว็บที่เป็น HTTPS ฟรีทันที เช่น `https://school-alert.vercel.app`

### วิธีที่ 2: อัปโหลดผ่าน Netlify Drop
1. เข้าไปที่ [app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์โปรเจกต์นี้ไปปล่อยในกรอบสี่เหลี่ยม
3. ระบบจะ Deploy เว็บไซต์และให้ลิงก์ HTTPS ฟรีทันที

## ⚙️ การเชื่อมต่อกับบัญชี OneSignal ของโรงเรียน

1. สมัครบัญชีฟรีที่ [OneSignal.com](https://onesignal.com/)
2. สร้าง App ใหม่ เลือกแพลตฟอร์ม **Web** และกรอก URL ของเว็บ (เช่น ลิงก์ที่ได้จาก Vercel หรือ Netlify)
3. ไปที่เมนู **Settings → Keys & IDs** แล้วคัดลอก:
   - **OneSignal App ID**
   - **REST API Key**
4. เปิดหน้าเว็บโรงเรียนของคุณ กดปุ่ม **"⚙️ ตั้งค่า OneSignal"** ที่มุมบนขวา แล้ววาง Key ทั้งสองตัวเพื่อเริ่มส่งแจ้งเตือนจริงได้ทันที!
